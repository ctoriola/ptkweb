# Brand source files

Original logo files supplied by PrimeTEK. The website uses vector versions
traced from these:

- `assets/img/logo/primetek-logo.svg` — wordmark (from `primetek-logo-orange-bg.png`)
- `assets/img/logo/primetek-mark.svg` — eagle "P" mark (from `primetek-mark-black.png`)

The favicon (`/favicon.ico`), `apple-touch-icon.png`, `icon-192/512.png`,
`primetek-logo.png` (used in search-engine structured data) and
`primetek-avatar.webp` are rendered from those SVGs.
